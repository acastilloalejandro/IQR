# Interoperability

IQR is designed to evolve with open standards.

| Concern | Target |
|---|---|
| Credential model | W3C Verifiable Credentials |
| Proofs | W3C Data Integrity / compatible proof mechanisms |
| Status | Bitstring Status List |
| Issuance / presentation | OpenID4VC |
| Compact encoding | CBOR / COSE |
| Visual carrier | QR Code |
| Proximity carrier | NFC |
| Transport | HTTPS |

Implementations should record exact versions and profiles used by each credential.
